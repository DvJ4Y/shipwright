# Lessons — every correction, as a rule

> `/session end` and `/learn` append here. Each entry is a rule and its reason, never a story
> of what went wrong. When one rule reaches three occurrences, propose an edit to the skill
> that should have prevented it; show the diff and apply it only on approval.

## Format

```
## YYYY-MM-DD — <topic> · #tag #tag
**Rule:** <what to do, phrased to prevent recurrence — one sentence>
**Why:** <the correction or evidence behind it — one line>
**Source:** <chat:YYYY-MM-DD | a repository path | you, YYYY-MM-DD>
**Occurrences:** <n> — <dates>
```

## How to write a lesson

| Do | Do not |
|---|---|
| Write the rule in the present tense: "Copy the label with the number." | Write history: "We quoted a target as a baseline." |
| Raise **Occurrences** when the same rule recurs | Add a second entry for the same rule |
| Tag the skill or surface the rule applies to | Put a fact about the business here; that is a row in `facts.md` |
