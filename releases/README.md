# Releases

One note per cycle, written by `/issue-tracker release` after reconciliation:
`releases/<cycle>-release-note.md`. Each note lists every item with its status from the
commitments vocabulary (`committed · in build · in UAT · deployed to prod`), the rollout
boundary beside `deployed to prod`, the impact chain, and the acceptance ids with production
evidence. The note is the source `/land` reads. Nothing here is edited by hand after
publication; a correction is a new note.
