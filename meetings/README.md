# Meetings

Workspace-scope meeting notes, one file per meeting: `meetings/YYYY-MM-DD-<name>.md`, written by
`/meeting-processor`. Feature-scope notes go to the feature's `internal/evidence/`; initiative-scope
notes to the initiative's `research/`. A figure said in a meeting is labelled
`operational — unverified` with "as stated in the meeting, <date>".
